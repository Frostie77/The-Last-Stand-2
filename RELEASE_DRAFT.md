# The Last Stand 2 Android v0.1.0

The first Android release of **The Last Stand 2**, powered by Ruffle and FrostFrontend.

- Remappable gamepad controls with twin-stick aiming and a controller-operated menu cursor.
- Relative and direct touch aiming, a touch joystick or D-pad, and a customizable touch layout.
- Original and stretched display modes, adjustable render resolution, and optional antialiasing.
- Combat audio timing and performance improvements for the supported v1.31 game file.
- Local saves and settings, a stereo speaker test, and optional update checks.

## Getting started

1. Install `The-Last-Stand-2-v0.1.0-Android.apk`. Requires **Android 8.0 or newer**.
2. Download the [v1.31 game file from Not Doppler](https://i.notdoppler.com/files/thelaststand2.swf).
3. Open the app and select `thelaststand2.swf` when prompted.

The APK requires a separate SWF import. Development testing covered gameplay and combat audio on the **AYN Odin 2 Portal**. The full campaign and other Android devices still need testing.
